# Código de conduta

Colabore com respeito. Assédio, discriminação, ameaças, exposição de dados pessoais e comportamento abusivo não são aceitos.

Aplica-se a issues, pull requests, discussões e demais espaços do projeto. Reporte incidentes ao proprietário por canal privado. O mantenedor pode pedir esclarecimentos, remover conteúdo, limitar participação ou encerrar interação. Não publique evidências sensíveis.

Este documento adapta princípios do Contributor Covenant sem incorporar seu texto integral.
