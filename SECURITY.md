# Política de segurança

## Reportar uma vulnerabilidade

Não abra issue pública para possível exposição de credencial, bypass de autorização, execução não autorizada, acesso a dados ou falha de isolamento. Use o recurso privado de segurança do GitHub deste repositório, se habilitado, ou contate o proprietário do repositório por canal privado.

Inclua impacto, reprodução mínima, versão da skill/Orca e evidência sanitizada. Não envie tokens, chaves, dumps, logs brutos ou dados de cliente.

## Escopo

Relatos úteis incluem falhas de orientação que possam induzir bypass de workspace trust, permissões, autenticação, isolamento de worktree ou revisão pós-worker.

Hermes, Orca, Antigravity e serviços de terceiros têm políticas e canais próprios. Este repositório não controla vulnerabilidades deles, mas relatos de interação insegura na documentação são bem-vindos.

## Resposta

O mantenedor confirma recebimento quando possível, avalia a reprodução e coordena uma correção. Não há SLA nem programa de recompensa declarado.
