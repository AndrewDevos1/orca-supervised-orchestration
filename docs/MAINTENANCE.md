# Manutenção

Ao atualizar exemplos, valide a CLI efetiva e registre versão e comandos usados. Revise links, caminhos, decisões de segurança e licenças.

Antes de release: varrer segredos e dados reais; verificar histórico e autores; validar Markdown; confirmar que nenhuma instrução contorna trust, autenticação, permissões ou Gate de Integridade.

Não copie logs de runtime, worktrees de clientes ou credenciais para este repositório.
