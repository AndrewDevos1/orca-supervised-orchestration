# Registro de publicação

A branch `main` contém o README inicial do repositório privado.

A branch `import/installed-skill-initial` contém a cópia exata da skill instalada no WSL no momento da publicação. O hash SHA-256 está versionado em `provenance/SKILL.md.sha256`.

Esta publicação não modifica a skill local e não implica instalação, merge, execução de worker ou autorização operacional adicional.
