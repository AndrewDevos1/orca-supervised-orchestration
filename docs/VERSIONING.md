# Versionamento

A versão da skill está no frontmatter de `SKILL.md`. Use SemVer enquanto o formato for mantido:

- MAJOR: incompatibilidade de contrato ou segurança;
- MINOR: orientação/capacidade compatível comprovada;
- PATCH: correção documental compatível.

Enquanto a documentação declarar experimental, uma versão não significa garantia de estabilidade. Registre mudança e evidência em `CHANGELOG.md`.
